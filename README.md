# Flask Login App 🔐

A simple authentication system built with Flask that supports user registration, login, logout, and profile management.

---

## 🚀 Features

- User Signup
- User Login / Logout
- Session management using Flask sessions
- Dashboard page (protected route)
- Edit profile functionality
- Change password feature
- Basic UI using HTML templates

---

## 🛠️ Tech Stack

- Python
- Flask
- Flask-Login
- HTML / CSS (Jinja2 templates)
